編集方針 / データの取り扱い

当サイトでは、以下の方針でイベント情報を収集・掲載しています:

  • 収集元: 公式サイト、公式SNS(Instagram, Facebook, X)、出展者投稿、当サイトへの直接掲載申請
  • 裏取り: 全イベントについて公式情報源(タイトル/og:title)に植物関連キーワードがあることを確認
  • 除外基準: チケット販売サイト・aggregator・名前が紛らわしい音楽イベントなどは登録しない
  • 更新頻度: 毎日午前にスケジュールタスクで新規イベントを自動収集。情報更新は週次以上の頻度で実行
  • データソース表示: 各イベント詳細ページのEVENT INFO欄に最終更新日と参照元(公式サイト/Instagram等)を明記

掲載情報の透明性を担保するため、データフィード(JSON / RSS / CSV / iCal)も公開しています。詳しくは API ドキュメント をご参照ください。

運営者の専門性

運営者はアガベ・塊根植物・ビザールプランツの愛好家として 5年以上 各種イベントへの参加・出展経験があります。植物即売会の現場感覚を活かして、業界内の主要イベントを網羅的に把握し、有用な情報を厳選して掲載しています。

運営の様子や最新の植物・イベントレポートは @m.z.plants で発信しています。

掲載依頼・修正依頼

イベント主催者・出展者の方で、新規掲載・修正・削除をご希望の場合は お問い合わせ または 掲載申請ページ からご連絡ください。原則として 48時間以内に対応します。

誤情報・古い情報の修正依頼は無料で対応いたします。
