## 補完手順

1. 「探すべき場所」のリンクを開く
2. メインビジュアル(横長推奨)のURLをコピー
3. 該当イベントの events.json エントリの `imageUrl` フィールドに貼り付け
4. `python3 build-detail-pages.py --slug <slug>` で当該ページのみ再生成して確認
5. PRまたは直接 main へコミット&プッシュ

## 自動化されている範囲

- `scripts/backfill-images.py`: og:imageが取得できる公式サイトURLがある場合
- `scripts/instagram-oembed.py`: Instagram投稿URLがあり、IG_OEMBED_TOKEN設定後

上記でもカバーできないのは「URLがそもそも events.json に未登録」のケース。新規イベント追加時に `url` か `imageUrl` を必ず入力するルール ([docs/event-data-prompt.md](event-data-prompt.md)) を厳守すれば、このリストは時間とともに小さくなります。
